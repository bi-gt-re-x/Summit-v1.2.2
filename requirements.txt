# Summit — backend dependencies.
#
#   python3 -m venv .venv-fastapi
#   .venv-fastapi/bin/python -m pip install -r requirements.txt
#   .venv-fastapi/bin/python run.py
#   .venv-fastapi/bin/python -m pytest        # the suite in tests/
#
# ## Python
#
# **3.12 or newer.** The venv in this checkout is on 3.13.15, from Homebrew.
#
# It used to be on 3.9.6 — the one that ships with Xcode's command line tools
# — and 3.9 reached end of life in October 2025, so it was taking no security
# patches at all. Nothing here needed 3.9 and nothing here was written to it,
# so the move was a new venv and one install:
#
#     brew install python@3.13
#     /opt/homebrew/bin/python3.13 -m venv .venv-fastapi
#     .venv-fastapi/bin/python -m pip install -r requirements.txt
#     .venv-fastapi/bin/python -m pytest
#
# That last line is the check that it worked: 83 passed, no warnings that were
# not there before. Rebuild the venv the same way on a fresh clone — the
# interpreter is the one thing in this file `pip install` cannot supply.
#
# ## Pinned, not floored
#
# These were `>=` ranges, which is a promise that every future release of six
# libraries will keep working — a promise nobody made. A `pip install` six
# months from now would have installed versions this app has never run against,
# and the failure would land on whoever cloned it next rather than on whoever
# chose the range. The versions below are the ones the suite in tests/ passes
# against; moving one is a deliberate edit and a test run.
#
fastapi==0.128.8
uvicorn[standard]==0.39.0

# Renders the Jinja templates in frontend/templates/. Kept while the React
# frontend is built alongside the old pages — see backend/routes/pages.py.
jinja2==3.1.6

# Signs the session cookie for Starlette's SessionMiddleware.
itsdangerous==2.2.0

# Only for werkzeug.security's password hashing. Accounts already in the
# database hold pbkdf2 hashes in werkzeug's format, so reading them back needs
# the same code that wrote them — see backend/tracking/auth.py.
werkzeug==3.1.8

# PostgreSQL, when DATABASE_URL is set — backend/database/pg.py. The binary
# wheel carries its own libpq, so nothing else needs installing; the pool keeps
# connections open between requests rather than one handshake per query.
psycopg[binary]==3.3.6
psycopg-pool==3.3.3

# Form parsing on the OAuth callback.
python-multipart==0.0.20

# Breaking a goal into its five checkpoints — backend/tracking/planner.py.
# Needs a key in the environment; without one the goals page shows the
# suggestion button as unavailable and everything else works as before.
#
# The Hugging Face path is one POST to an OpenAI-shaped endpoint and needs no
# SDK — httpx is listed because planner.py imports it directly. It already
# arrives as a dependency of anthropic; naming it here means the cheap path
# does not quietly break if the paid one is ever dropped.
httpx==0.28.1
anthropic==0.121.0

# --- Tests ----------------------------------------------------------------
# The suite in tests/ — see tests/conftest.py for how it gets a database of
# its own. Listed with everything else rather than in a second file: one
# install command is one fewer thing for a fresh clone to get wrong, and the
# suite is not optional if the app is going to keep the guarantees in it.
pytest==8.4.2
