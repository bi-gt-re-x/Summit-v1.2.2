Frequently Asked Questions

Where is my data stored?

Everything lives in one SQLite database on the server that runs Summit. Nothing is uploaded to a cloud service. See our Privacy Policy for details.

I lost my streak — can it be restored?

Streaks count consecutive days with completed work. If a day was genuinely logged and the streak still reset, that's a bug — report it with your task history and we'll look into it.

How do XP and levels work?

Completing tasks and focus sessions earns XP. Each level requires more XP than the last, and your Growth page grades your consistency over time.

Can I use Summit on multiple devices?

Yes. Your account lives on the server that runs Summit, so any device that can reach it sees the same progress. To move to a new server, copy the database file (data/summit.db).

Does Summit cost anything?

No — Summit is free, with every feature included. There are no paid tiers, subscriptions, or ads.
